# Katkıda bulunma

Değişiklikler için bir branch açın; ilgili testleri çalıştırıp pull request gönderin.
Node.js 24.14 ve pnpm 10.28.2 kullanın. Kurulum ve doğrulama adımları README.md dosyasındadır.
Gerçek API anahtarlarını, OAuth kayıtlarını, hesap oturumlarını veya kişisel verileri eklemeyin.
İç paket adları ve veri yolları uyumluluk nedeniyle korunur.
