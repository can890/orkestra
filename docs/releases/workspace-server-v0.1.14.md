# Workspace Server v0.1.14

- **Çalışan ajana araya girme:** Uzak (SSH) projelerde ajan çalışırken yazılan mesaj kuyruğa düşmeden çalışan tura eklenir (Claude ve Codex); ajan cevap verip işine devam eder. Alt+Enter mesajı eskisi gibi sıraya ekler.
- **Yan cevap:** Çalışan tura mesaj alamayan sağlayıcılarda (Antigravity) soru, ana ajan kesilmeden ayrı ve salt okunur kısa bir oturumla cevaplanır.
- **Antigravity geçmişi:** Oturum yeniden yüklendiğinde (sunucu yeniden başlatıldığında) Antigravity konuşmasının geçmişi artık kaybolmuyor.
- **Diğer:** Kimi K3.1 Pro modelleri, geri sarmada yok sayılan dosyaların korunması, sohbet başlığına gizli bağlam sızmasının önlenmesi ve sohbet içi widget desteği.

Protokol 10.1; 10.x istemcilerle uyumludur. Linux x64 arşivi ve SHA-256 doğrulama dosyası.
